# COFIVERP Workout Tracker

Mobile-friendly eight-week strength and aerobic training journal.

## Features

- Gym A, Gym B, optional Gym C, and Baguio dumbbell sessions
- Record sets, weights, repetitions, and repetitions in reserve
- Review training history and exercise progress
- Log incline walking and aerobic exercise
- Export and restore JSON backups

## Publish on GitHub Pages

1. Open [Repository Settings → Pages](https://github.com/poginuxx/cofiverp-workout-tracker/settings/pages).
2. In **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main**, **/(root)**, and **Save**.
4. After deployment, access [the tracker](https://poginuxx.github.io/cofiverp-workout-tracker/).

## Data and privacy

The code is public. Workout entries are stored locally in this browser, not in the GitHub repository. There is no cross-device syncing. Export backups regularly, especially before clearing browser data or changing devices. Do not commit personal training backups or sensitive health data to a public repository.
